# ADR-002 — Convenciones iniciales de código

## Estado
Aceptada para el inicio del desarrollo.

## Decisión
Los conceptos del dominio conservarán la terminología del ERS y DAS en español (`Obra`, `Cliente`, `Convenio`, `Estimacion`, etc.) para mantener trazabilidad. Los nombres estructurales y técnicos de arquitectura usarán términos habituales del ecosistema Java (`domain`, `application`, `infrastructure`, `api`, `config`).

No se mezclarán traducciones distintas para un mismo concepto de dominio.
